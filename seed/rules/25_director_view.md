# 25 · 导演视角：先想清楚拍哪一刻，再动笔

> 方法源头：一位摄影从业者总结的「先定文化主题 → 再定动作 / 环境 / 镜头 / 光影」。
> 这里只收**拍摄语言**，不收平台参数。

## 一、动笔前先答一个问题

**这张拍的是哪一刻，为什么动人？**

同一个主题至少想到三种拍法，再挑最贴用户意图的一种；意图不明时，把三种摆给用户选。

示例——「热闹的舞狮表演」：

| 拍法 | 景别/机位 | 讲的是 | 关键元素 |
|---|---|---|---|
| A 腾跃瞬间 | 中近景，低机位略仰 | 力量与热闹 | 狮头腾空、狮身贴地、人群虚化、鞭炮纸屑、地面被踩踏 |
| B 狮头细节 | 特写 85mm，浅景深 | 手艺与精细 | 绒毛根根分明、鳞片反光、狮眼圆睁、竹篾骨架 |
| C 散场之后 | 中景，平视略高 | 疲惫与余韵 | 队员摘头套后大汗、狮头搁在板凳上、场地一地红纸 |

> 判断标准：真正影响成片的，不是形容词写得多不多，而是有没有把画面想清楚。

## 二、摄影语言词典

### 机身与胶片
| 写法 | 含义 | 用在 |
|---|---|---|
| `Live-action 35mm film still` | 实拍 35mm 胶片剧照 | 要「像电影截帧」而非「像插画」 |
| `film grain` | 胶片颗粒 | 配上面一条，防数码塑料感 |
| `documentary realism` | 纪实写实 | 民俗、劳动者、生活场景 |

### 焦段
| 焦段 | 效果 | 用在哪 |
|---|---|---|
| `16mm / 24mm` | 广角，环境包进来，有张力 | 大场景、建筑、群像 |
| `35mm` | 接近纪实现场感 | 街头、民俗活动、剧照感 |
| `50mm` | 接近人眼 | 中性叙事 |
| `85mm` | 压缩 + 柔化背景 | 肖像、手艺人、细节 |
| `100mm macro` | 微距 | 纹理、器物、食材 |

### 景别与机位
`close-up` / `medium close-up` / `full shot` / `wide shot`；
`eye level` / `low angle` / `high angle` / `over-the-shoulder`。

### 景深
浅：`shallow depth of field` + `f/1.4–f/2.8`；深：`f/8–f/11`。

### 光线
- `Dim indoor light and natural window light` —— 作坊、手艺人
- `natural daylight` —— 户外民俗
- `sunlight from behind-left` —— 逆侧光勾轮廓，空中微尘可见
- `light smoke in the air` —— 让光「看得见」

## 三、民俗 / 纪实题材的默认收尾句

```
documentary realism, muted colors, film grain,
no CGI, no beauty retouching, no oversharpening, no text, no watermark.
```

中文：纪实写实，克制的低饱和色彩，胶片颗粒，无 CG 感，无美颜磨皮，无过度锐化，无文字，无水印。

> 这五个「不」不是负面堆砌，是**把 AI 感逐项关掉**。

## 四、母版

```
Live-action 35mm film still, [身份+年龄+关键特征] [具体动作] in [地点, 省市, 国家],
[1-2 个传统材料/工具], [背景 2-3 个层次元素与人群处理方式].
[光线：类型+方向+空气介质], [焦段] lens, [景别], documentary realism,
muted colors, film grain, no CGI, no beauty retouching, no oversharpening,
no text, no watermark.
```

## 五、与七块的关系

不替代七块，而是**动笔前先回答拍哪一刻**。
顺序固定：**导演提问 → 七块填充 → 中英双版 → 自检**

## 六、参数归属

正文不写 `--ar` / `--style raw` / `--s`。
用户指定模型且要这组风格时，才在末尾附加并标注「模型专属参数」；未指定一律不加。
