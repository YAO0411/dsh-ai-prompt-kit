# 45 · 任务提示词结构（模式 B：让 AI 干活，而不是出图）

> 用户说不清需求时，产出一份可直接交给另一个 AI 的提示词。
> **只产提示词，不替他做任务**，除非他明说要成品。

## 一、七段式（缺一段即不合格）

| # | 段名 | 写什么 | 反例 |
|---|---|---|---|
| 1 | **角色** | 你是……（领域 + 经验层级 + 立场） | 「你是一个 AI 助手」 |
| 2 | **目标** | 交付什么、给谁用、用来干什么 | 「帮我写点东西」 |
| 3 | **输入** | 我会提供什么（贴在哪、什么格式、哪些是权威） | 只写「根据我的要求」 |
| 4 | **输出格式** | 表格 / 清单 / 段落 / 字数 / 标题层级 / 是否中英对照 | 「写得详细一点」 |
| 5 | **硬约束** | 必须做到 + 绝对不许做（禁止项要可检查） | 「别写得太水」 |
| 6 | **未知处理** | 缺信息时怎么办：先问 / 标注假设 / 直接选默认 | 没写 → AI 自己编 |
| 7 | **验收标准** | 什么样的结果算合格，3～5 条可逐项打勾 | 「好就行」 |

## 二、模板

```
【角色】你是 <领域> 的 <角色>，风格 <X>，不做 <Y>。

【目标】交付 <产物>，用于 <场景>，读者是 <谁>。

【输入】<我会给你什么>；格式 <X>；其中 <哪些字段/部分是权威>。

【输出格式】
- 结构：<标题层级 / 表格 / 编号清单>
- 长度：<X 字 / X 行 / X 个镜头>
- 语言：中文为主；如涉及英文内容，中英各一份
- 必须包含：<字段清单>

【硬约束】
必须：
- ...
绝对不许：
- 编造未提供的事实 / 数据 / 链接
- 输出「以上」「希望对你有帮助」这类套话

【未知处理】
信息不足时：先问我最多 <N> 个最关键的问题，不要自己补；
若必须补，在输出末尾单列「我做的假设」一节。

【验收标准】
1. ...
2. ...
```

## 三、三条铁律

1. **不清楚就先问，不脑补** —— 与出图模式同一条。
2. **只产提示词，不替用户做任务** —— 他说「帮我写周报」，交的是「写周报的提示词」，不是周报本身。
3. **禁止项要可检查** —— 写「不许出现具体人名」而不是「注意隐私」。

## 四、常见模糊需求 → 该问什么

| 用户说 | 该确认的（最多 2 个） |
|---|---|
| 「帮我写个东西」 | 交付物是什么类型？给谁看？ |
| 「做个计划」 | 周期多长？已经定了哪些不能动？ |
| 「分析一下这个」 | 要结论还是要过程？输出多长？ |
| 「优化一下」 | 优化目标：更快 / 更准 / 更好读？ |
| 「写个提示词」 | 给哪个 AI 用、要它产出什么？ |
