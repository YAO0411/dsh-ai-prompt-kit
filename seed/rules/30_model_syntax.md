# 30 · 模型语法禁区（防混用，不做平台适配）

> 本文件只有一个作用：**别把 A 模型的专属语法写进 B 模型的提示词**。
> 默认输出「通用描述层」，除非用户指定了模型。

## 一、默认策略

| 情况 | 做法 |
|---|---|
| 没说用哪个模型 | 只输出七块里的 1–7 块，**不加任何参数** |
| 指定了模型 | 只在英文版末尾追加该模型专属语法，且只加该模型支持的 |
| 不确定 | 不加，并在末尾写「当前未加模型专属语法」 |

## 二、混用禁止表

| 语法 / 参数 | 只能用于 | 依据 |
|---|---|---|
| `--no`、`--ar`、`--s`、`--style raw`、`::` 权重、`--sref`、`--oref`、`--stylize` | Midjourney | A（部分方向）/ 其余未核实 |
| `negative_prompt` 字段 | SD 系、Imagen 系 | A；FLUX.2 **明确不支持**（B） |
| `quality` / `complexity` / `background` / `output_format` / `markup` | OpenAI GPT Image **API 参数** | A（**这些不是提示词文本**，不要写进提示词） |
| `guidance_scale`、采样步数 | 本地开源权重 | B/C |
| 十六进制色值 | FLUX 系被推荐 | B/C，其他勿默认加 |
| `"A photo of…"` 开头 | Imagen 3 官方建议 | A，其他未核实 |
| 提示词里的「no X」 | GPT Image 可当约束；**Midjourney 上可能适得其反** | A |

## 三、各模型行文口味（写英文版时参考，非强制）

| 模型 | 口味 | 长度倾向 |
|---|---|---|
| Midjourney | **短而简单最好**，少用长清单；精确名词；写想要的，不写不想要的 | 最短 |
| FLUX 2 | **连贯句子**，不要 SD 式关键词堆；否定改成正向状态 | 30～80 词 |
| GPT Image | 自然语言详细描述即可；结构化短句也行；编辑时明确 keep | 中长 |
| SD 3.5 | 结构化 + 强负面提示；可写电影术语 | 中 |

**正向改写**：`没有杂物` → `smooth bare concrete`；`不模糊` → `everything in sharp focus`。
这条对**所有模型都更安全**，可作默认写法。

## 四、能力边界（别承诺做不到的事）

- 光线**质感**可靠，**方向**只是请求，实测常被忽略
- 镜头参数是「外观线索」，不是物理模拟（A，OpenAI）
- 十六进制色值只是强引导，实测有偏差
- 画面文字：加引号、写位置、保持简短；描述性小字容易乱码
- 需要像素级不变 → 合成回原图，不要指望模型「保持不变」
