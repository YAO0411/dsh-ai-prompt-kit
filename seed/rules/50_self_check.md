# 50 · 交付前自检

> 人工自检清单。`promptlib_check` 已把其中可机检的部分自动化；这份用来补机器检不出的判断。

## 一、九项常规

| # | 检查 | 不合格的样子 |
|---|---|---|
| 1 | 意图对得上吗 | 用户要产品图，写成了 lifestyle 场景 |
| 2 | 有可见细节吗 | 全篇是「氛围」「高级」「质感」 |
| 3 | 物理合理吗 | 光源在左、影子在右；物体悬空；接触处没有阴影 |
| 4 | 真实感够吗 | 出现 plastic skin / CGI / 3D render 倾向的词 |
| 5 | 构图说清了吗 | 没写景别、机位、主体位置 |
| 6 | 用户约束保住了吗 | 用户说「不要人」，结果写了人物 |
| 7 | 有空词堆砌吗 | `8K, masterpiece, ultra detailed` |
| 8 | 有乱塞模型语法吗 | 给 Midjourney 写 `negative_prompt` |
| 9 | 追问克制吗 | 一次问五个问题；或该问的没问 |

## 二、五个高危（出现即重写）

1. **主体埋在风格词后面** → 主体必须在前 10 个词内
2. **只写否定** → 改成正向状态（`没有杂物` → `光滑的混凝土地面`）
3. **中英不一致** → 中文写「仰拍」，英文写 `high angle`，直接算错
4. **英文版是中文直译** → 出现 `very very`、`there is a`、`the picture is`
5. **承诺效果** → 「一定出 XX」，改写为「倾向于 XX」

## 三、最后一问

> **是否含具体镜头/光向？是否有皮肤/材质纹理？是否避免空话词？**

三个都「是」才能发出去。

## 四、对照测试方法（验证规则时用）

- 同一需求，旧提示词 vs 新提示词
- **同模型、同设置**，每组多出几张，减少偶然
- **每轮只改一个变量**
- 比较：人物结构 / 材质 / 背景 / 构图 / 指令遵循
- 记录结果，不凭感觉

> 「训练」的真实含义：不是微调模型，是**用对照结果反推哪条规则有效**，然后改 `rules/`。

## 五、测试设计要先查天花板

如果主体本身已经很粗糙（`weathered face` + 高龄劳动者），
再加强纹理词不会有增量，只会过冲。

**测之前先问：这个主体的默认状态是什么？我要测的变量真的还有空间吗？**
