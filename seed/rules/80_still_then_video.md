# 80 · 先出静帧，再图生视频

> **凡是视频，一律先出静帧、再图生视频，不直接文生视频。**

一句话理由：直接文生视频，模型每帧都在重新「猜」毛发、皱纹、手指、牙齿，猜出来就是塑料感；
图生视频里一张图定死质感，模型只负责让它动。

## 六步流程

1. **定镜头清单**：几条镜头、每镜几秒、讲什么。先有表，再写词。
2. **写静帧提示词**：按七块或散文式（看题材），每镜一条。
3. **出静帧**：每镜出 2～3 张候选（不是固定 4 张），挑最好的一张。
4. **四处验收**（见下）。
5. **图生视频**：只写运动，不重写画面。
6. **剪辑卡点**：配乐与音效在剪辑里加，不在提示词里。

## 四处验收

| # | 查什么 | 不合格的样子 |
|---|---|---|
| 1 | 头发边缘有无均匀亮光 | 一圈发光光环 = rim light 过曝 |
| 2 | 身体有无受光面 / 背光面 | 全身平光 = 没有体积 |
| 3 | 牙齿是否太整齐太白 | 假牙感 |
| 4 | 手指结构是否完整 | 多指 / 少指 / 融合 |

## 图生视频的写法

**只写运动**，不要重写画面：

```
[运镜一句] + [画面内元素的变化：人物动作 / 光影 / 气流]
```

**固定收尾**：

```
silent, no audio track, no dialogue, no voice, no lip movement, no text, no watermark.
```

## 六类踩过的坑

| ❌ 写法 | 会出什么 | ✅ 改成 |
|---|---|---|
| `rim light` / 发丝勾边 / backlight | 头发一圈发光光环 | 正面或斜前方 30° 硬光 + `no rim light, no edge glow on hair or fur` |
| `backlit haze` / 逆光扬尘 | 贯穿全屏的放射光柱 | 尘土写「一颗一颗、近地密向上稀」+ `no god rays, no lens flare` |
| 浅景深拍近景 | 手指糊成一坨 | `f/5.6–f/8` 深景深 + `no portrait mode, no bokeh` |
| 未定位的 `deep wrinkles, sun spots` | 全脸皱褶密度均匀像核桃壳 | 逐条写位置（鼻唇沟、眼尾、额头、耳垂）并说明深浅不一 |
| 脸上列瑕疵清单 | 每条变成一个红点或被误画 | 脸上只留 3 个以内肤质词，真实感靠光位与距离 |
| 正脸 + 露牙笑 + 特写 | 当前模型最崩的组合 | 改中景 / 侧脸 / 背影，或让脸只占画面高度 1/5 |
| 图生视频写「转头/抬头/转身/说话」 | 必重画脸，且真的生成语音 | 全部删掉，改眨眼、呼吸、发丝、蒸汽、水、风；加 `mouth stays closed and still` |
| 图生视频写 `dust shifts` | 凭空加一大块尘雾 | 写 `no steam plume, no smoke, no haze, no dust cloud` |
| 竖屏需求不写画幅 | 出横图 | 开头写 `VERTICAL FRAMING, 9:16 portrait, 1080x1920` |

## 静帧「平台味」的根因

皮肤油光、光线均匀好看、颜色干净、构图完整 —— 根因是
`glazed by the light`、`local contrast low, shadows lifted` 这类「调舒服」的写法。

改法：`matte, dusty, unwashed`、`nothing lifted, nothing crushed`，
并主动写不该有的东西（门边的钉子、石阶上的干草与污渍、墙上起皮）。
