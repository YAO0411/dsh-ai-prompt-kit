# 90 · 散文式提示词（人文 / 纪实 / 旅拍视频的默认写法）

> 对这类题材，**模型对「拍摄意图 + 纪律」的响应，强于对参数清单的响应**。
> 告诉它「像一位纪录片摄影师在现场长期观察人物」，比堆 `f/5.6, 85mm, rim light` 管用得多。

## 七段式（一段话，不列要点）

```
【风格定位】介质 + 影调 + 颗粒 + 构图态度 + 空气感
【光影氛围】自然光优先 + 允许面部阴影 + 不用商业补光
【运镜方式】固定机位 / 缓慢推进 / 轻微手持跟拍 + 像谁在拍
【情绪表达】不夸张不煽情 + 靠细节眼神沉默传情
【声音与氛围】环境音优先 + 保留哪些具体声音 + 配乐克制
【剪辑节奏】不快切 + 不夸张转场 + 允许留白 + 有呼吸感
【最终效果】观众像亲身经历 + 明确列出要避免的 AI 痕迹
```

## 示例

```
【风格定位】35mm 电影胶片质感，克制的高光过渡，暗部保留细节，
不完全对称构图，画面有空气感。
【光影氛围】以自然窗光、阴天散射光、清晨与黄昏的柔和光为主。
允许人物面部有阴影，不用商业补光打平。
【运镜方式】固定机位为主，偶有极缓推进，像一位纪录片摄影师在现场长期等待。
【情绪表达】不夸张不煽情，情绪落在手上、眼神和沉默的间隙里。
【声音与氛围】环境音优先：远处人声、工具声、风穿过屋檐。配乐克制到几乎听不见。
【剪辑节奏】不快切，不夸张转场，允许留白，镜头有呼吸感。
【最终效果】观众像亲身在场，而不是在看一支广告。
避免：皮肤磨平、光线均匀好看、构图过于完整、颜色过于干净。
```

## 为什么有效

- **给了拍摄意图**，模型知道整体调性，不会每句各自为政
- **给了纪律**（不夸张、不煽情、克制），等于给了负向约束的正向写法
- **写了「要避免的 AI 痕迹」**，比罗列 `no CGI` 更贴合这类题材

## 什么时候不用

| 场景 | 用什么 |
|---|---|
| 产品图、商业图、特效、需精确控光的多主体 | 七块（`10_seven_blocks.md`） |
| 需要指定焦段/光圈来控制景深 | 七块 |
| 人文 / 纪实 / 旅拍 / 生活类**视频** | 本文 |

两种按题材选，**不混用**。

## 与七块的关系

不是替代。散文式回答「这段影像想表达什么、按什么纪律拍」，
七块回答「这一帧里有什么、怎么拍」。

**视频**优先散文式；**单帧图**优先七块。
